MASTER PROMPT — SERVICES PAGE BACKGROUND / ENVIRONMENTAL LIGHTING V3

OBJECTIVE

Refine ONLY the background/environmental visual system of the existing Services page.

The current result already has the correct dark + violet identity, so DO NOT redesign the visual language.

The goal now is to make the background feel like a sophisticated, proprietary technological environment rather than a dark purple webpage background.

The final result should feel:

- premium
- cinematic
- technical
- deep
- spatial
- restrained
- futuristic
- intentional

Think:

"advanced technology environment"

NOT:

"purple SaaS landing page"

==================================================
1. PRESERVE THE CURRENT DESIGN
==================================================

DO NOT redesign:

- navigation
- typography
- headings
- cards
- icons
- content
- page structure
- spacing
- existing purple brand identity

DO NOT remove the existing purple illumination.

DO NOT replace it with blue/cyan.

DO NOT introduce additional accent colors.

DO NOT add decorative illustrations.

This task is specifically about refining the BACKGROUND ENVIRONMENT.

==================================================
2. THE CORE PROBLEM TO FIX
==================================================

The current background is visually clean, but it still behaves too much like:

    dark base + purple tint + particles

Instead, it needs to behave like:

    dark environment
          ↓
    spatial illumination
          ↓
    technical structure
          ↓
    subtle depth particles
          ↓
    content surfaces

Purple must behave like LIGHT.

It should not behave like a background COLOR.

==================================================
3. CREATE A REAL LIGHTING HIERARCHY
==================================================

Establish three lighting levels.

LEVEL 1 — PRIMARY LIGHT

Create one dominant but extremely soft violet atmospheric field.

Position it around the upper Services/Hero region.

It should subtly illuminate:

- Our Services
- surrounding negative space
- upper Hackathons region

But it must NOT become a visible purple blob.

The center should be slightly brighter than the surrounding environment.

The transition must be extremely gradual.

--------------------------------------------------

LEVEL 2 — SECONDARY LIGHT

Introduce a second weaker violet atmospheric field lower on the page.

Position it around the Training / Student Development transition.

This light should NOT have the same intensity as the primary light.

It exists to create vertical rhythm.

--------------------------------------------------

LEVEL 3 — AMBIENT LIGHT

Use extremely subtle atmospheric illumination in distant areas.

This should be barely perceptible.

Its purpose is preventing the page from becoming visually dead.

==================================================
4. STOP USING A SINGLE GLOBAL GRADIENT
==================================================

Do NOT use one giant gradient covering the entire Services page.

The page is long.

Instead construct one CONTINUOUS ENVIRONMENT containing several overlapping atmospheric fields.

Conceptually:

TOP

    deep darkness
          ↓
    primary violet atmosphere
          ↓
    Our Services
          ↓
    gradual atmospheric falloff
          ↓
    Hackathons
          ↓
    darker transition
          ↓
    secondary violet atmosphere
          ↓
    Training Programs
          ↓
    gradual falloff
          ↓
    Student Development
          ↓
    subtle atmospheric lift
          ↓
    Workshops
          ↓
    dark continuation

The transitions must be continuous.

Never visually divide the page into separate background sections.

==================================================
5. CREATE LIGHT POOLS, NOT PURPLE AREAS
==================================================

This distinction is extremely important.

BAD:

    █████████████████
    █████████████████
    █████████████████

GOOD:

             soft light
          ░░░░░░░░░░░░
       ░░░░░░░░░░░░░░░░
     ░░░░░░░░░░░░░░░░░░
        ░░░░░░░░░░░░
            ↓
          darkness

The light should have a center of influence and a very long falloff.

==================================================
6. USE CONTROLLED ASYMMETRY
==================================================

The current background is too predictable.

Do not center every atmospheric field.

Use controlled asymmetry.

For example:

- primary illumination slightly offset horizontally
- secondary illumination offset in another direction
- different intensity levels
- uneven atmospheric density
- different particle density zones
- varying grid visibility

But maintain visual balance.

The composition must feel designed, not random.

==================================================
7. CREATE A VISUAL LIGHT PATH
==================================================

The user's eye should naturally travel down the page.

Create this hierarchy:

    OUR SERVICES
         ↓
    HACKATHONS
         ↓
    TRAINING
         ↓
    STUDENT DEVELOPMENT
         ↓
    WORKSHOPS

Use extremely subtle atmospheric emphasis around these areas.

Do NOT put a glow directly behind every heading.

Instead allow nearby illumination to frame the content.

The user should subconsciously perceive:

    light → content → darkness → light → content

==================================================
8. ADD NEGATIVE-SPACE CONTRAST
==================================================

Do NOT illuminate the entire page.

Some areas should intentionally become darker.

For example:

    LIGHT
      ↓
    CONTENT
      ↓
    DARK TRANSITION
      ↓
    LIGHT
      ↓
    CONTENT

This creates depth.

Darkness is not empty space.

Darkness is part of the composition.

==================================================
9. IMPROVE THE GRID
==================================================

The existing technical grid is currently too weak to contribute meaningfully.

Do NOT simply increase its opacity globally.

Instead:

- increase visibility very slightly in selected areas
- fade it naturally into darkness
- allow atmospheric light to reveal portions of it
- keep other areas nearly invisible
- vary density subtly

The grid should feel like a technical structure underneath the environment.

It should NOT look like:

    CSS background-grid.png

It should feel embedded in the environment.

==================================================
10. GRID DEPTH
==================================================

Create the illusion of depth using multiple grid strengths.

NEAR:

slightly clearer lines

MID:

very subtle

FAR:

almost invisible

This should produce environmental depth without becoming visually obvious.

==================================================
11. PARTICLES — REDUCE THEIR IMPORTANCE
==================================================

Keep the particles.

Do not add more.

The current particles are acceptable, but they should become a secondary detail.

Use:

- extremely small particles
- varied opacity
- varied depth
- irregular distribution
- very slow movement

Keep the region immediately around major headings relatively clean.

Particles should live mostly in negative space.

They should be discovered rather than announced.

==================================================
12. PARTICLE DENSITY MAP
==================================================

Do NOT distribute particles uniformly.

Avoid:

    * . * . * . * . *
    . * . * . * . * .
    * . * . * . * . *

Instead:

    sparse
       ·

           ·
    ·

                 ·  ·

       ·

Create natural clusters and empty areas.

==================================================
13. CARD / ENVIRONMENT RELATIONSHIP
==================================================

The cards are currently very dark.

KEEP THEM DARK.

Do not brighten the cards to solve the background problem.

Instead make the environment around them provide subtle spatial separation.

Cards should feel like dark physical surfaces inside the environment.

Desired relationship:

    atmospheric light
          ↓
    surrounding space
          ↓
       dark card
          ↓
      subtle border

Do NOT add strong card glows.

==================================================
14. FIX THE GENERATIVE AI CARD VISUAL DISCONNECT
==================================================

The active/hovered Generative AI card currently attracts significantly more attention than the surrounding environment.

This makes it feel like a separate visual system.

Reduce its environmental glow intensity.

The card can still have an active state.

But its illumination must feel like it belongs to the same violet lighting system as the page.

The environment should remain dominant.

==================================================
15. INTRODUCE SUBTLE CARD ENVIRONMENTAL SHADOW
==================================================

Cards should create slight visual depth against the background.

Use subtle:

- shadow separation
- edge contrast
- ambient occlusion-like darkness

Do NOT create heavy shadows.

Do NOT use black outlines.

Do NOT make cards look floating in empty space.

==================================================
16. PURPLE COLOR DEPTH
==================================================

Keep the current purple family.

Do not introduce unrelated colors.

Use several tonal levels:

deep near-black violet
        ↓
black-violet
        ↓
deep violet
        ↓
soft violet
        ↓
lavender
        ↓
white

The majority of the background must remain near-black.

Purple should occupy selected atmospheric regions.

==================================================
17. NO GIANT PURPLE BLOB
==================================================

This is critical.

Do NOT create obvious:

- circles
- radial-gradient discs
- glowing blobs
- halos
- spotlights

If a gradient is visible as a "shape", it is too strong or too small.

Make atmospheric fields extremely large with long falloff.

==================================================
18. NO EXCESSIVE BLUR
==================================================

Do not solve atmosphere using massive blur.

Avoid expensive blur-heavy layers where possible.

Prefer:

- large radial gradients
- pseudo-elements
- opacity
- masking
- lightweight canvas
- GPU-friendly transforms

Use blur only when visually necessary.

==================================================
19. ATMOSPHERIC DEPTH
==================================================

Create three environmental depth layers.

MACRO:

large atmospheric illumination

MESO:

technical grid / subtle structural pattern

MICRO:

particles

Hierarchy:

    MACRO = strongest
    MESO  = subtle
    MICRO = weakest

If particles become more noticeable than the atmospheric system, reduce them.

==================================================
20. EDGE DARKNESS
==================================================

Keep the outer edges dark.

But do not create an obvious vignette.

The viewer should not see:

"there is a vignette."

They should simply perceive:

"the environment fades into darkness."

==================================================
21. TOP NAVIGATION REGION
==================================================

The background behind the navigation should remain relatively restrained.

Do not put a bright purple glow directly behind the navigation.

The navigation should feel anchored above the environment.

The existing active Services pill can remain visually prominent.

==================================================

==================================================

The "Our Services" heading should remain the strongest visual element.

Use atmospheric light behind and around the hero.

Do not put a glow directly behind the letters.

Do not reduce heading contrast.

The heading should sit inside the atmosphere rather than compete with it.

==================================================
23. HACKATHONS REGION
==================================================

Hackathons should receive slightly less atmospheric emphasis than the hero.

The environment should gently transition from the hero illumination toward a darker region around the cards.

This makes the cards feel grounded.

==================================================
24. TRAINING REGION
==================================================

Introduce the secondary atmospheric field around this area.

The transition should be gradual enough that the user cannot identify where the light begins.

This creates a new visual chapter without creating a new background.

==================================================

## DO'S AND DON'TS

### ✅ DO

1. Use #f4f0ff for body text (NOT pure white #ffffff)
2. Use AeonikPro weight 500 at 48-72px for headings
3. Use 5px radius for buttons, 16px for cards, 32px for badges, 999px for nav
4. Apply inset white glow for elevation (NOT drop shadows)
5. Use #9382ff sparingly for links, active states, focus rings
6. Use cosmic gradient ONLY on text and thin strokes
7. Set page background to #030014

### ❌ DON'T

1. Use bold (600+) or extra-bold (700+) weights
2. Use drop shadows on cards or panels
3. Add accent color to large fills or backgrounds
4. Use border-radius values outside the defined set
5. Use pure white #ffffff for body text
6. Introduce semantic colors (red/green/yellow)
7. Use multiple accent hues (single lavender #9382ff only)
