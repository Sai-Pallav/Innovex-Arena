# INNOVEX ARENA — Fueling the Future of Creators

A modern, high-performance web application for **Innovex Arena**, a tech-driven startup building AI-based products, cloud solutions, and empowering the next generation through workshops, hackathons, and training programs.

![Innovex Arena](https://images.unsplash.com/photo-1518770660439-4636190af475?w=1200&auto=format&fit=crop&q=80)

---

## ✨ Features

- **Cyber Aesthetic Hero**: Viewport-centered hero section with dynamic multi-color atmospheric glow, subtle cyber grid, glassmorphic specialization capsule, and high-impact typography.
- **Programs & Classes**: Showcase for Live Online, Campus, and Hybrid learning modes.
- **Events & Hackathons**: College hackathons, technical workshops, and innovation challenge trackers.
- **Product Suite**: Showcase of AI and cloud-native solutions.
- **Career & Internship Portals**: Interactive application forms with client-side validation and toast notifications.
- **Responsive Navigation**: Sticky glassmorphic navbar with smooth in-page routing and mobile drawer.
- **Dark Mode First**: Tailored cyber color palette with HSL color tokens and custom gradient utilities.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sai-Pallav/Innovex-Arena.git
   cd Innovex-Arena
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
