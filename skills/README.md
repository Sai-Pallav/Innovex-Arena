# Available Skills

## design-taste-frontend
For landing pages, portfolios, and redesigns with real design direction. Anti-slop frontend skill — reads the brief, infers the right design direction, and ships interfaces that do not look templated. Real design systems when applicable, audit-first on redesigns, strict pre-flight check.

## emil-design-eng
UI polish philosophy, animation decisions, micro-details. Encodes Emil Kowalski's philosophy on UI polish, component design, animation decisions, and the invisible details that make software feel great.

## figma-designer
Analyzes Figma designs and generates implementation-ready specs. Use when a Figma link or design screenshots are provided. Requires Figma MCP server connection.

## frontend-design
Production-grade frontend interfaces with high design quality. Use when building web components, pages, artifacts, posters, or applications (websites, landing pages, dashboards, React components, HTML/CSS layouts). Generates creative, polished code and UI design that avoids generic AI aesthetics.

## gsap-frameworks
GSAP animations in Vue, Svelte, and other non-React frameworks. Covers lifecycle, scoping selectors, and cleanup on unmount. Use when working with Vue, Nuxt, Svelte, SvelteKit, or asking about GSAP with onMounted, onMount, onDestroy.

## impeccable
UI/UX auditing, polish, visual hierarchy, accessibility, motion. Use when designing, redesigning, critiquing, or polishing any frontend interface — websites, landing pages, dashboards, product UI, components, forms, onboarding, and empty states. Covers typography, spacing, layout, color, motion, micro-interactions, and reusable design systems.

## shadcn-ui
shadcn/ui component patterns, setup, and configuration. Provides complete shadcn/ui component library patterns including installation, configuration, and implementation of accessible React components. Use when setting up shadcn/ui, installing components, building forms with React Hook Form and Zod, or customizing themes with Tailwind CSS.
